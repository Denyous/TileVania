# Tile-Vania

**Tile-Vania** is a 2D platformer game developed using Unity and C#.

The project focuses on classic platformer gameplay mechanics, including character movement, enemy behaviors, and level design using Unity's Tilemap system.

##  Game Overview

Tile-Vania is a 2D platformer where players navigate through levels, overcome obstacles, and encounter enemies.

The project focuses on implementing core platformer mechanics and exploring Unity's game development workflow.

##  Technical Features & Systems

### Gameplay Systems

- **Character Controller:** Implements player movement and platformer controls, including jumping and movement mechanics.
- **New Input System:** Uses Unity's New Input System for handling player input and controls.
- **Enemy AI & Behaviors:** Implements enemy behaviors and basic AI logic to create interactive gameplay challenges.
- **Tilemap System:** Uses Unity Tilemap tools to design and build 2D game environments.
- **Prefab Workflow:** Uses reusable Prefabs to organize game objects and improve development efficiency.
- **Collision & Physics:** Utilizes Unity's 2D physics and collision systems for player and enemy interactions.
